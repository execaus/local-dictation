# Local Dictation 0.2.1 — исправления для рабочего Mac

Предварительный выпуск для проверки на целевом Mac. Запись и распознавание остаются полностью локальными; сетевых функций в приложении нет.

## Исправлено

- В едином окне **«Настройки…»** появились разделы «Микрофон», «Клавиши» и «Словарь». Можно выбрать конкретный микрофон или системный вход.
- Приложение больше не подаёт термины словаря модели как постоянную подсказку. Словарь по-прежнему исправляет написание после распознавания.
- Почти беззвучная запись показывает ошибку проверки микрофона вместо случайной расшифровки.
- После получения доступа к «Универсальному доступу» приложение автоматически включает правый Control без перезапуска.
- Ручной запуск лучше сохраняет целевое приложение и восстанавливает фокус редактора перед вставкой.

## Установка

Закройте прежнюю версию, замените `.app` из архива и откройте настройки приложения. Сначала выберите рабочий микрофон, затем проверьте запись короткой фразы в IDE. Если macOS запросит разрешения повторно, выдайте их новой установленной копии приложения. Сборка подписана локально (ad hoc), без нотарификации Apple.

Для возврата доступен [предыдущий выпуск](https://github.com/execaus/local-dictation/releases/tag/v0.2.0). Контрольная сумма архива включена в `SHA256SUMS`.
