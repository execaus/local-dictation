# Local Dictation 0.2.4

Обычный релиз для macOS. Запись и распознавание остаются локальными. Единственное сетевое действие приложения — проверка и загрузка обновления с GitHub после нажатия соответствующего пункта меню.

- Запуск по умолчанию перенесён на правую Option: два быстрых нажатия включают запись, удержание записывает до отпускания. Настройка прежнего правого Control при обновлении автоматически заменяется новым вариантом; пользовательские сочетания сохраняются.
- Esc во время записи отменяет её без распознавания и вставки. Запись после двойного нажатия Option завершается повторным двойным нажатием или через меню.
- Вставка больше не зависит от имени IDE. Если активное поле недоступно через Accessibility, приложение вводит текст системным клавиатурным событием в текущее активное окно. Если активное приложение сменилось, текст остаётся доступен для повторной вставки.
- Из настроек удалены счётчик и подсказки для правого Control.
- В меню появился пункт «Проверить и установить обновление…». Sparkle проверяет подписи ленты и архива, затем предлагает установить новую версию без ручного копирования приложения. Фоновая проверка отключена.
- Панель записи и настройки получили более лёгкие полупрозрачные материалы и оформление в стиле macOS Tahoe.

Для запасной вставки нужно заранее поставить курсор в нужное поле: если приложение не показывает поле через Accessibility, его тип проверить невозможно. Сборка подписана локально (ad hoc), без нотарификации Apple. Закройте прежнюю копию и установите новую из архива. Контрольная сумма архива находится в `SHA256SUMS`.
