# Local Dictation 0.2.5

- После запуска записи двойным нажатием правой Option одно нажатие той же клавиши завершает запись и запускает локальное распознавание. Esc по-прежнему отменяет запись без вставки.
- В разделе «Общие» настроек показана версия приложения и находятся кнопки обновления и открытия «Универсального доступа».
- У приложения появилась новая иконка: звуковая волна на полупрозрачной плитке с индикатором записи. Она видна в Finder и в сведениях о приложении.

Диктовка остаётся локальной. Проверка обновлений обращается к GitHub только по нажатию кнопки в настройках. Архив и лента обновлений подписаны отдельно; закрытый ключ остаётся в локальной Связке ключей Mac сборки.
