# Local Dictation 0.2.7

- В разделе «Общие» добавлена выключенная по умолчанию галочка «Нажимать Enter после диктовки». При включении после обычной успешной вставки текста приложение нажимает Enter в активном приложении.
- Если вставка не удалась или активное приложение сменилось, Enter не отправляется. Повторная вставка сохранённого текста из меню тоже не нажимает Enter.

Опция действует для любого активного поля: в некоторых редакторах Enter может добавить строку или выполнить другое действие. Диктовка, словарь и диагностика остаются локальными; сеть используется только при проверке обновлений по кнопке.
