# Локальная диктовка 0.1.0

Первая публичная сборка для Mac с Apple Silicon. Приложение записывает речь по горячей клавише, распознаёт её встроенной многоязычной моделью Whisper и вводит текст в активное поле IDE или другого приложения. Распознавание работает без интернета; модель входит в архив.

## Возможности

- **Control–Option–Пробел:** начать и завершить диктовку.
- **Control–Option–Esc:** отменить запись.
- Компактная панель состояния записи и обработки.
- Локальный редактируемый словарь технических терминов.
- Обработка аудио в памяти без истории расшифровок.
- Ввод текста в активное поле без автоматической отправки сообщения.

Сборка проверена пользователем на MacBook Pro M4 Pro с macOS Tahoe 26.7. В проекте используется `whisper.cpp` v1.7.5 и модель `large-v3-turbo-q5_0`.

## Установка

Скачайте `LocalDictation-0.1.0-macos-arm64.zip`, распакуйте и откройте `LocalDictationSpike.app`. Предоставьте доступ к микрофону и «Универсальному доступу» в системных настройках. При первом запуске или после обновления macOS может запросить разрешения повторно.

Архив имеет локальную подпись разработчика и не нотариализован Apple. На Mac с политикой допуска только нотариализованных приложений используйте согласованный корпоративный способ установки или соберите проект из исходников. Для корпоративного допуска также требуется проверка сетевой активности, описанная в `SECURITY.md`.

SHA-256 архива указан в `SHA256SUMS`.
