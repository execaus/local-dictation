# Local Dictation 0.2.8

- Приложение локально считает завершённые записи с каждого микрофона. Перед новой записью оно обновляет набор устройств; если набор изменился, выбирает доступный микрофон с наибольшим счётчиком. При равенстве выбирается системный вход.
- Ручной выбор в настройках действует, пока набор устройств не изменится. Если микрофон отключится непосредственно перед записью или его запуск не удастся, приложение попробует другие доступные входы вместо ошибки о сохранённом устройстве.
- В разделе «Микрофон» показан счётчик записей для текущего выбора. В журнал не попадают аудио и текст диктовки.

Диктовка работает локально. Проверка обновлений обращается к GitHub только по нажатию кнопки в настройках.
