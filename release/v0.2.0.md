# Local Dictation 0.2.0 — предварительный выпуск

Этот выпуск предназначен для проверки нового управления диктовкой на целевом Mac. Распознавание речи, словарь и вставка текста остаются полностью локальными; сетевых функций и проверки обновлений в приложении нет.

## Новое

- По умолчанию два быстрых нажатия **правого Control** начинают запись. **Esc** останавливает её, запускает распознавание и вставляет текст.
- Удержание **правого Control** начинает запись через короткую паузу; отпускание останавливает её и запускает распознавание.
- В меню появился пункт **«Управление клавишами…»** для выбора собственной клавиши или сочетания. Прежнее **Control–Option–Пробел** можно выбрать там.
- **Control–Option–Esc** по-прежнему отменяет запись без вставки.

## Установка и проверка

Скачайте архив для Apple Silicon, закройте старое приложение и замените его новым `.app`. Если macOS запросит разрешение «Универсальный доступ» повторно, разрешите его для нового приложения. Проверьте оба жеста в целевой IDE. Предыдущий [стабильный выпуск](https://github.com/execaus/local-dictation/releases/tag/v0.1.0) остаётся доступен для возврата.

Архив содержит модель Whisper; загрузка модели при запуске не требуется. Подпись сборки локальная (ad hoc), нотарификации Apple нет, поэтому корпоративная политика может ограничить запуск. Контрольная сумма SHA-256 находится в `SHA256SUMS`.
