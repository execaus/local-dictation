# Локальная диктовка для macOS

Текущая версия записывает речь с микрофона в память, распознаёт её встроенной моделью Whisper `large-v3-turbo-q5_0` и вводит текст в активное поле через системные события клавиатуры. Приложение не вызывает сетевые API, не скачивает модель при запуске и не сохраняет аудио или расшифровки на диск.

## Сборка и запуск

Нужны macOS и Swift 6. В репозитории есть исходники и `whisper.cpp` XCFramework. Модель из-за размера не хранится в Git: положите проверенный `ggml-large-v3-turbo-q5_0.bin` в `Resources/` вручную или загрузите её на компьютере для сборки:

```sh
zsh scripts/fetch-model.sh
```

Скрипт сверяет SHA-1 модели. Загрузка нужна только при сборке из исходников. Готовое приложение из Release содержит модель и работает без интернета. Соберите приложение:

```sh
zsh scripts/make-app.sh
```

Откройте приложение из `dist/LocalDictationSpike.app` через Finder. Его значок волны появится в строке меню. По умолчанию управление выполняется **правым Control**: два быстрых нажатия начинают запись в активном поле IDE до **Esc**, а удержание начинает запись через короткую паузу и завершает её при отпускании. Первая запись запросит доступ к микрофону. Готовность показывают красный значок и компактная панель; после остановки приложение локально распознаёт речь и вставляет текст. **Control–Option–Esc** отменяет запись без вставки; блокировка экрана или переход Mac в сон тоже её отменяют.

В меню **«Управление клавишами…»** можно записать собственную клавишу или сочетание, включая прежнее **Control–Option–Пробел**. В режиме правого Control одиночное короткое нажатие ничего не делает. Настройка сохраняется на этом Mac. Если системная клавиша занята, приложение сохранит прежний способ запуска и покажет ошибку. Если доступ к «Универсальному доступу» ещё не разрешён, приложение временно использует **Control–Option–Пробел**.

Для автоматического ввода требуется разрешение **Системные настройки → Конфиденциальность и безопасность → Универсальный доступ**. При ошибке нажмите **«Открыть настройки»**, затем включите `LocalDictationSpike.app` в списке. Если приложения нет, добавьте его кнопкой `+` из папки `dist`.

Если фокус сменился или вставка не удалась, приложение показывает расшифровку и предлагает скопировать её вручную. Этот выбор использует системный буфер обмена. Приложение никогда само не нажимает Enter. В защищённые поля ввод отключён.

Словарь открывается из меню приложения. В нём можно добавлять варианты распознавания и правильное написание. Правила сохраняются локально через настройки macOS; термины также подаются модели как подсказка перед распознаванием. Запись и обработка показаны на компактной панели. Перед первым использованием с рабочими данными проверьте точность и правила ИБ на целевом Mac.

## Проверка компонентов

```sh
dist/LocalDictationSpike.app/Contents/MacOS/LocalDictationSpike --self-check
dist/LocalDictationSpike.app/Contents/MacOS/LocalDictationSpike --model-check
codesign --verify --verbose=1 dist/LocalDictationSpike.app
```

`--model-check` обрабатывает нулевой тестовый буфер; он не использует микрофон или рабочие данные. В ограниченной песочнице инструментов Metal может быть недоступен — тогда проверку нужно запускать в обычном терминале macOS.

Модель `large-v3-turbo-q5_0` многоязычная, размер около 547 MiB. Её SHA-1: `e050f7970618a659205450ad97eb95a18d69c9ee`. На синтетической фразе с русской речью и терминами `PostgreSQL`, `useEffect` она оказалась точнее моделей `base` и `small`; это лишь начальная проверка, реальную речь надо оценить отдельно. Движок: `whisper.cpp` v1.7.5. Лицензии вложены в `.app`.

Полное [ТЗ](SPEC.md) фиксирует требования первой версии и критерии приёмки. [Разбор локальности и проверок ИБ](SECURITY.md) описывает границы гарантии.
