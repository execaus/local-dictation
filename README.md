# Локальная диктовка для macOS

Текущая версия записывает речь с микрофона в память, распознаёт её встроенной моделью Whisper `large-v3-turbo-q5_0` и вводит текст в активное поле через системные события клавиатуры. Диктовка не использует сеть, модель вложена в приложение, аудио и расшифровки не сохраняются на диск. Только пункт меню «Проверить и установить обновление…» обращается к GitHub.

## Сборка и запуск

Нужны macOS и Swift 6. В репозитории есть исходники и `whisper.cpp` XCFramework. Модель из-за размера не хранится в Git: положите проверенный `ggml-large-v3-turbo-q5_0.bin` в `Resources/` вручную или загрузите её на компьютере для сборки:

```sh
zsh scripts/fetch-model.sh
```

Скрипт сверяет SHA-1 модели. Загрузка нужна только при сборке из исходников. Готовое приложение из Release содержит модель и работает без интернета. Соберите приложение:

```sh
zsh scripts/make-app.sh
```

Откройте приложение из `dist/LocalDictationSpike.app` через Finder. Его значок волны появится в строке меню. По умолчанию управление выполняется **правой Option**: два быстрых нажатия начинают запись, повторные два завершают её и запускают распознавание; удержание начинает запись через короткую паузу и завершает её при отпускании. Первая запись запросит доступ к микрофону. После остановки приложение локально распознаёт речь и вставляет текст. **Esc** отменяет текущую запись без распознавания и вставки; **Control–Option–Esc** тоже отменяет запись. Блокировка экрана или переход Mac в сон отменяют запись.

В меню **«Настройки…»** находятся разделы **«Микрофон»**, **«Клавиши»** и **«Словарь»**. Можно выбрать конкретный микрофон или системный вход; выбор применяется к следующей записи и хранится только на этом Mac. В разделе клавиш можно записать собственную клавишу или сочетание, включая прежнее **Control–Option–Пробел**. В режиме правой Option одиночное короткое нажатие ничего не делает. Если системная клавиша занята, приложение сохранит прежний способ запуска и покажет ошибку. Если доступ к «Универсальному доступу» ещё не разрешён, приложение временно использует **Control–Option–Пробел** и автоматически переключится на правую Option после выдачи доступа.

Окно настроек открывается на текущем рабочем столе, в том числе рядом с полноэкранной IDE. После закрытия оно создаётся заново при следующем вызове. Локальный журнал отмечает этапы показа окна, если оно снова не появится.

Правая Option отслеживается и в самом приложении, и при работе в IDE. Журнал отмечает только события этой клавиши-модификатора, без вводимого текста.

Для автоматического ввода требуется разрешение **Системные настройки → Конфиденциальность и безопасность → Универсальный доступ**. При ошибке нажмите **«Открыть настройки»**, затем включите `LocalDictationSpike.app` в списке. Если приложения нет, добавьте его кнопкой `+` из папки `dist`.

Поле для вставки проверяется после распознавания. Если приложение не показывает поле через «Универсальный доступ», текст всё равно вводится системным клавиатурным событием в активное окно по текущему фокусу клавиатуры. Если активное приложение сменилось, текст остаётся в памяти приложения: выберите нужное поле и нажмите **«Вставить готовый текст в выбранное поле»** в меню значка. Можно также скопировать текст вручную; только это действие использует системный буфер обмена. Приложение никогда само не нажимает Enter. Если защищённое поле видно через «Универсальный доступ», ввод в него блокируется; когда поле не видно, проверить его тип невозможно.

Меню **«Открыть журнал диагностики…»** открывает локальный журнал этапов работы. Он помогает определить, на каком шаге приложение закрылось, и не содержит аудио или расшифровок. При системном сбое macOS может дополнительно сохранить отчёт о падении в системной папке DiagnosticReports.

Обновления проверяются только по нажатию пункта **«Проверить и установить обновление…»**. Sparkle загружает подписанную ленту и, если есть новая версия, предлагает скачать и установить подписанный архив. В фоне приложение обновления не проверяет. Для каждого следующего GitHub Release необходимо публиковать вместе с архивом новую подписанную `appcast.xml`; закрытый ключ подписи хранится в связке ключей входа на Mac сборки и не добавляется в репозиторий. На автоматическую синхронизацию этого ключа через Apple ID полагаться нельзя: при смене Mac его нужно безопасно экспортировать и перенести отдельно. Если ключ утерян, сборки с локальной подписью нельзя будет обновлять этим способом без ручной переустановки.

В словаре можно добавлять варианты распознавания и правильное написание. Правила сохраняются локально через настройки macOS и применяются после распознавания; это не заставляет модель повторять слова словаря при тихой записи. Почти беззвучная запись завершается сообщением о проверке микрофона. Запись и обработка показаны на компактной панели. Перед первым использованием с рабочими данными проверьте точность и правила ИБ на целевом Mac.

## Проверка компонентов

```sh
dist/LocalDictationSpike.app/Contents/MacOS/LocalDictationSpike --self-check
dist/LocalDictationSpike.app/Contents/MacOS/LocalDictationSpike --model-check
dist/LocalDictationSpike.app/Contents/MacOS/LocalDictationSpike --audio-check
codesign --verify --verbose=1 dist/LocalDictationSpike.app
```

`--model-check` обрабатывает синтетический тон; `--audio-check` проверяет обнаружение источников звука. Они не записывают звук с микрофона или рабочие данные. В ограниченной песочнице инструментов Metal может быть недоступен — тогда проверку нужно запускать в обычном терминале macOS.

Модель `large-v3-turbo-q5_0` многоязычная, размер около 547 MiB. Её SHA-1: `e050f7970618a659205450ad97eb95a18d69c9ee`. На синтетической фразе с русской речью и терминами `PostgreSQL`, `useEffect` она оказалась точнее моделей `base` и `small`; это лишь начальная проверка, реальную речь надо оценить отдельно. Движок: `whisper.cpp` v1.7.5. Лицензии вложены в `.app`.

Полное [ТЗ](SPEC.md) фиксирует требования первой версии и критерии приёмки. [Разбор локальности и проверок ИБ](SECURITY.md) описывает границы гарантии.
