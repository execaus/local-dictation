# Локальность и проверка ИБ

Приложение записывает аудио в память процесса, распознаёт его встроенной моделью и вводит текст в активное поле. Диктовка, словарь и диагностика работают без сети. По нажатию пункта меню «Проверить и установить обновление…» Sparkle обращается к GitHub за лентой и архивом новой версии. Фоновая проверка обновлений и системное профилирование отключены. Модель, движок и их лицензии находятся внутри `.app`.

При выборе двойной правой Option приложение наблюдает системные события изменения клавиш-модификаторов. Во время записи оно временно регистрирует Esc для отмены и проверяет только его код в резервном мониторе. Приложение не читает символы набираемого текста и не передаёт события по сети. Локальный журнал отмечает только факт нажатия правой Option, без текста. Для наблюдения нужен «Универсальный доступ»; обычное сочетание регистрируется через системный механизм горячих клавиш без мониторинга ввода.

Если поле ввода не представлено в дереве Accessibility, приложение отправляет текстовое клавиатурное событие в активное приложение. Тип такого поля, в том числе признак защищённого ввода, проверить нельзя. Перед диктовкой пользователь должен поставить курсор в нужное поле; если активное приложение сменилось перед вставкой, операция отменяется и текст остаётся в памяти для повторной вставки.

**Граница проверки:** офлайн-работа диктовки не заменяет сетевой аудит готовой сборки на рабочем компьютере. Для допуска ИБ рекомендуется наблюдать исходящие соединения приложения и его процессов при запуске, диктовке и явной проверке обновлений. После ввода текста в IDE за дальнейшую обработку отвечает IDE. Лента и архив обновлений подписываются EdDSA; Sparkle проверяет подписи до установки. Закрытый ключ хранится в локальной Связке ключей, а не в GitHub.

Ключ подписи создаётся утилитой Sparkle в связке ключей входа на Mac сборки. Apple ID не является гарантированным резервным хранилищем этого ключа. Для выпуска обновлений с другого Mac его нужно экспортировать и перенести безопасным способом; секрет нельзя добавлять в GitHub, репозиторий или диагностические журналы. При утрате ключа выпущенные с локальной подписью приложения потребуют ручной переустановки для перехода на новый ключ.

Системный App Sandbox не включён: глобальная вставка использует macOS Accessibility, для которого Apple указывает [ограничения в sandboxed apps](https://developer.apple.com/forums/thread/794253). Поэтому запрет исходящих соединений следует обеспечить корпоративной политикой хоста. Само приложение не содержит функций передачи данных.
